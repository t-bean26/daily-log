Set up twice-a-day reminders (iPhone)

Web apps on iPhone can't schedule their own notifications, so use the built-in Reminders app:

  1. Open Reminders and tap New Reminder. Title it "Log today".
  2. Tap the (i) button, turn on Date and Time (for example 12:00 PM), set Repeat to Daily.
  3. Paste this app's link into the URL field:
  4. Make a second one for the evening (for example 9:00 PM).

Tap the notification, then tap the link to open the app.
